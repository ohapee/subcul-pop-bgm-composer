# 🍹 サブカルポップBGMコンポーザー

**純喫茶 × ネオ渋谷系 × ピクセルチル** ── 集中と創作のための作業用ポップBGMジェネレーター

先行ツールである「ゲームBGMコンポーザー」（8bit・レトロゲーム調）と「ゆるかわBGMコンポーザー」（お昼寝・オルゴール癒やし調）の**中間的な位置づけ**となる、都会的でお洒落、かつ軽くポップな作業用BGM（勉強・プログラミング・デスクワーク用）のプロンプトを作成できるWebアプリケーションです。

---

## 🌐 公開ページ（GitHub Pages）

- **公開URL**: [https://ohapee.github.io/subcul-pop-bgm-composer/](https://ohapee.github.io/subcul-pop-bgm-composer/)
- スマートフォン（iPhone / Android）およびパソコンのモダンブラウザでそのまま動作します。
- インストール不要・完全無料・広告なし。PWA（Progressive Web App）に対応しており、ホーム画面に追加してアプリとして利用できます。

## ✨ 主な特徴とこだわり

### 1. サブカルチャー世界観＆モチーフ
- **レトロフューチャー純喫茶**: ネオンメロンソーダ、カセットテープの温もり、アイスの浮かぶグラス
- **ピクセルチル / 8bitローファイ**: ゲームボーイ風の小気味よいピコピコと、まったりした勉強用ビートの融合
- **ネオ渋谷系ポップ**: 軽快なリズムギター、爽やかで知的なシティ感
- **深夜ドライブ / シティポップ調**: 煌めく夜景、洗練されたウォーキングベースライン
- **電脳ベッドルームポップ**: Y2Kサイバーギーク感のあるミニマルで心地よい電子音
- **下北沢インディーチル**: レコードショップや古着屋を思わせるアコースティックな温もり
- **雨の日のコーディング**: 窓を叩く雨音とローズピアノで深い没入感を実現

### 2. 都会的でお洒落な和声（コード進行）
- **丸サ進行（Just the Two of Us / IVmaj7 - III7 - VIm7 - I7）**: 都会的でお洒落な名曲定番コード
- **シティポップ・メジャー7th**: 爽快で透明感のあるアーバンスタイル
- **ネオソウル・マイナー7th**: 知的で集中が途切れない深みのあるジャズ和声
- **渋谷系ポップペンタ**: 弾むような陽気でレトロなメロディ

### 3. メロディライン（主旋律）とハイブリッド編成
- **メロディライン担当楽器の個別設定**: 温かみのある**ローズピアノ（Rhodes）**、レトロな**8bit矩形波シンセリード**、透明感のある**ベル系プラックシンセ**、軽快な**クリーンギター/アコギ**、カフェ感溢れる**ヴィブラフォン/鉄琴**、切ない**メロトロン風フルート/口笛**、幻想的な**ウィスパー・ボイスチョップ**、都会的な**メロウ・サックス**、素朴な**トイピアノ**などから主旋律の音色を明示可能。
- **メロディラインの楽器固定オプション（一貫性キープ）**: AI音楽生成（Suno, Udio, Google Flow Music等）において、途中でリード楽器がコロコロ変わったりボーカルにすり替わるのを防ぐ強力なプロンプト制約・除外指示（Negative Prompt）を自動注入。「最初から最後まで一貫した音色で奏でる」指示を徹底します。
- **🍃 思いっきり音の数を減らすオプション（余白・静寂・ミニマル空間）**: 音符を過密に敷き詰めず、音数を極限まで間引き、音と音の間の静寂・ブレス（余白）を最大限に活かした「引き算の美学」によるチルサウンドを指示可能。AI特有の詰め込みすぎを徹底排除するNegative Prompt（`dense notes, crowded arrangement, busy arpeggios`等）も自動付与され、試聴プレビューでも自動的にポツリ…ポツリ…としたミニマル演奏に変化します。
- 伴奏・バッキングとして**8bitアルペジオ**、**ウォーキングベース**、**ローファイ・シャッフルドラム**、**アコギのカッティング**を融合。
- 作業中の思考を邪魔しない「**歌声なし（インストゥルメンタル）**」に徹底最適化。

### 4. 🎀 Hyper-Kawaii ＆ 🖤 Yami-Kawaii ニュアンス制御（パステル電脳 × ダーク甘）
サブカルポップの要となる2大カワイイ美学を、「なし（標準）」「ほんのり（隠し味）」「全開（MAX）」の3段階で独立制御できます。

- **🎀 Hyper-Kawaii（超絶カワイイ・パステル・キラキラ電脳）**:
  - パステルネオンの電脳空間、炭酸のように弾けるバブルガム感、キラキラと降り注ぐクリスタルチャイムの倍音をブレンド。
  - 試聴プレビューでもメロディに高域のキラキラ倍音レイヤーが合成されます。
- **🖤 Yami-Kawaii（病みかわいい・ダーク甘・アンニュイ・退廃美）**:
  - どこか切なくアンニュイなメロウ感、カセットテープの劣化のようなピッチの揺らぎ（ワウ・フラッター）、甘さと微熱が混ざり合う退廃美を演出。
  - 試聴プレビューでも微細なデチューンとビブラートによる切ない揺らぎが付与されます。
- **★ 病み甘ハイブリッド配合**:
  - Hyper と Yami の両方をONにすることで、「キラキラとした甘さの中にほの暗い毒と切なさが潜む」エモーショナルなドリームポップ・サブカルチャーサウンドが完成します。プロンプト本文、Suno/Udioタグ、除外指示、試聴プレビューのすべてに反映されます。

### 5. 🫧 サブカルKawaii派生スタイル（地雷系・天使界隈・ゆめかわいい・量産型）
サブカルチャーを彩る象徴的な派生スタイルをワンタップで掛け合わせ、プロンプト・タグ・試聴プレビューを特化させることができます。

- **🖤 地雷系（ダークエレクトロ・甘辛・重低音）**:
  - 重みのあるベースラインとエレクトロビート、黒とピンクのコントラスト、メンヘラ的でエモーショナルなダークエレクトロの甘辛アクセント。試聴プレビューでも重厚なサブベースがレイヤーされます。
- **👼 天使界隈（水色×白・サイバー透明感・儚い浮遊感）**:
  - 水色と白を基調とした澄んだ透明感、サイバーで儚い浮遊感、羽毛やエンジェルチャイムを思わせる無機質でドリーミーなアンビエントチル。試聴プレビューでも高域の澄み渡るクリスタルベルが重なります。
- **🦄 ゆめかわいい（パステル・メルヘン・ドリーミー）**:
  - パステルカラーの夢の世界、メルヘンでドリーミーなオルゴールやトイサウンド、ファンタジックで甘いメルティポップ。試聴プレビューでも優しいオルゴール和音が重なります。
- **🎀 量産型（あざと可愛い・王道キラキラアイドルポップ）**:
  - あざと可愛いガーリーな魅力、王道アイドル風のきらめくシンセ、キャッチーで弾むような愛されポップ。

### 6. 🎮 レトロゲーム効果音 ＆ ☕ ギーク・サブカル環境音
- **ゲーム効果音（8bit・レトロゲームアクセント）**:
  - **8bitピコピコ音**: 小気味よい電子ビープアクセント
  - **ピコーン！**: ひらめき・決定・カーソル音
  - **プユゥ〜ん / ぷよ〜ん**: コミカルなバウンス・ピッチベンド急降下音
  - **コイン獲得音**: ゲームボーイ風のチャリン音
  - **パワーアップ音**: 上昇アルペジオファンファーレ
  - **ジャンプ音**: ピョンと弾むレトロジャンプ
  - **ポーズ音**: ゲーム一時停止（ピポッ）
  - **1UP音**: 歓喜のジングル
- **純喫茶・サブカル環境音＆アクセント**:
  - **エンジェルチャイム**: 天使界隈を彩る澄み渡るクリスタルの余韻
  - **マジックスター**: ゆめかわいい星の瞬き・フェアリースパークル音
  - **病みハートビート**: 地雷系の心拍・ドクン…と沈み込む低音の脈動
  - カセットテープのカチッ音、レコード針音、メロンソーダの炭酸シュワシュワ音、メカニカルキーボード打鍵音、オールドデジカメのシャッター音、雨音、レコードスクラッチ。
- **クリックで即座に試聴可能**: 画面上の効果音チップをクリックすると、Web Audio APIによる合成効果音（ピコピコ、ピコーン、プユゥ〜ん、エンジェルチャイム等）がその場で鳴り、音色を確認しながら直感的に選べます。

### 7. Web Audio API によるリアルタイム試聴（プレビュー機能）
- ブラウザ上の内蔵シンセサイザーで、選択したテンポ・調性・メロディ音色・Kawaii要素・派生スタイルに基づきリアルタイム生成して試聴可能。
- 選択したゲーム効果音・サブカル効果音も、演奏中にリズミカルに自動挿入されます。
- 16ステップのレトロLEDインジケーターがリズムに合わせて点灯します。

### 8. 最新のAI音楽生成モデルに対応
- **Google Flow Music** に最適化されたプロンプト形式
- **Suno** / **Udio** 向けのタグ・スタイル指定形式（`[Lead: ...] [Consistent Lead Throughout]` など）
- プロンプトコピー、除外指示（Negative Prompt）コピー、URL共有、プリセット保存（JSON書き出し/取り込み）機能を完備。

## 📱 スマートフォンでのご利用方法

1. ブラウザ（SafariまたはChrome）で公開URLを開きます。
2. **iPhoneの場合**:
   - 画面下の共有ボタン（四角から矢印が出ているアイコン）をタップ
   - **「ホーム画面に追加」** を選択
3. **Androidの場合**:
   - メニュー（縦の3点リーダー）をタップ
   - **「アプリをインストール」** または **「ホーム画面に追加」** を選択
4. ホーム画面にメロンソーダとカセットテープのアイコンが追加され、全画面アプリとして起動できます。

## 💻 ローカル環境での起動方法

パソコンのローカル環境で直接動かす場合は、以下のスクリプトを利用できます。

```bash
# ローカルWebサーバーを起動（自動でブラウザが開きます）
./run_server.sh

# スマホ接続モード（同一Wi-Fi内のスマホからアクセスできるQRコードを表示）
./run_mobile.sh
```
